## Usability direction

Current shortest path: **make once in the extension → save locally → switch page →
choose a saved QR → click the field → Preview → Insert QR**. Preview checks layout
and fit, not scan success. Keep Undo and clear refusal messages.

Possible later refinements, not shipped here:

- Remember the last selected saved QR so repeat insertion takes fewer clicks.
- An explicit **Save to Aqrobat** or **Copy for Aqrobat** transfer from the website,
  with a deliberate extension import action. This needs a separate bridge/permission
  design; copying text today does not populate the saved library.
- A public recipe example gallery whose entries can be downloaded/imported. Other
  people’s recipe payloads should be visible before saving/inserting.

No background clipboard watcher or extra host permissions are necessary for the
current workflow. Make only the next refinement supported by the owner’s review.
