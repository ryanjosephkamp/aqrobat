# Phase 32 — continuous native text with source boundary guards

Preregister exactly three finder-only native text sources. Monaco 14 px / 14 px,
weight 400 throughout, black, zero tracking, no glyph transform, no ligatures.
One continuous selectable text node across the complete 25-module field, 300
explicit rows. Ordinary word spaces, whole dark/light words from phase17;
exclude isolated i. Semantically disconnected words are not natural prose.

Replace the three independently justified columns with one left-aligned field.
Use actual Monaco advance, exact 499-character rows, source DP on complete words
and spaces. The general source objective maximizes intended dark/light ink mass;
a whole word midpoint must match the selected bank. These source-only dark
boundary guards are fixed before any native result: 0, 0.12 and 0.24 modules.
Apply guards uniformly to all intended dark finder cells inside the source field,
not just to previously wrong sampled cells. No payload, format or timing data.
The guard expands source word selection, never modifies an image or reader.

edge allowance may reduce context-dependent candidate shifts. Require actual
selected geometry, not ideal source-center coverage. Record post-return jsQR
full-resolution selected H/V and both true diagonal runs, connected-quad spans,
balance and stable-wide rows using the preserved passive probe. Keep this strict
native gate separate from ZXing error-reporting sampled 147-cell / 12-ray gate.
Error reporting is diagnostic and never ordinary acceptance or passive-equivalent.

on every exact native PNG; OpenCV supplies an ordinary reader outside ZXing.

resampling, decoder tuning or hidden graphics. Retain accidental decoded bytes

row ink clearance >= 2 px; neighboring glyph ink bounds must not overlap;
