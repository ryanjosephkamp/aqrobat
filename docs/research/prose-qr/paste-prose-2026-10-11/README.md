# Standard-page prose and actual Word paste

Open [the local evidence guide](index.html) or [the offline generator](page-studio.html).

The accepted narrow example uses one complete 1,114-word mixed-case passage in a 6.25in editable text table at 8pt. Native Word-to-Word paste preserves its words, letter colors, width, row spacing and page. Both Samsung apps scan both its PDF and original PNG according to the owner; Apple Vision recovers the exact URL. Other primary readers fail, and arbitrary new wording is not guaranteed to scan.
